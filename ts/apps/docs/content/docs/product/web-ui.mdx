title: Web UI Guide
description: How to use the Earthed web interface — sidebar, timeline, reader, and feed lists.
---

The web app has three main areas: a sidebar for navigation, a timeline for browsing entries, and a reader view for reading.

## Sidebar

The sidebar shows:

- **Timeline** — all entries from all feeds, newest first.
- **Starred** — entries you have starred.
- **Search** — full-text search across all entries.
- **Feeds** — your subscriptions, grouped by folder.
- **Lists** — feed lists you own and lists you follow.

Click any item to filter the timeline. On mobile, the sidebar collapses into a drawer.

## Timeline

Each entry card shows the feed title, entry title, publication date, and a content preview. Unread entries have a dot indicator. Click an entry to open it in the reader.

Click the star icon on a card to star or unstar it — the change is immediate. Entries are marked as read when you open them. Mark all entries in a feed as read from the feed's context menu in the sidebar.

## Reader view

The reader shows the full entry content. Press `Esc` or the back button to return to the timeline. Links open in a new tab.

## Search

Search runs a full-text query across all entry titles and content. Type a query and press Enter. Results appear in the timeline like any other filtered view.

## Feeds

Subscribe to a feed by clicking **Add Feed** in the sidebar, pasting a URL, and clicking **Subscribe**. You can pass a website URL — Earthed discovers the feed automatically. The feed title and site URL are populated after the first refresh.

Create folders to group feeds by topic and assign feeds to them when subscribing. Deleting a feed removes it and all its entries permanently.

## Feed lists

From **Lists** in the sidebar you can create, share, follow, and import feed lists. See [Feed Lists](/docs/feed-lists) for the full guide.

## API tokens

Manage API tokens from the settings page. The token value is shown only once at creation — save it immediately. See [Authentication](/docs/authentication) for details.
