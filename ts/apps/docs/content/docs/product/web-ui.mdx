title: Web UI Guide
description: How to use the Planetary web interface — sidebar, timeline, reader, and feed lists.
---

The Planetary web app has three main areas: a sidebar for navigation,
a timeline for browsing entries, and a reader view for reading.

## Sidebar

The sidebar is your control center. It shows:

- **Timeline** — all entries from all feeds, newest first.
- **Starred** — entries you have starred.
- **Search** — full-text search across all entries.
- **Feeds** — your subscriptions, grouped by folder.
- **Lists** — feed lists you own and lists you follow.

Click any item to filter the timeline. The current selection is
highlighted in the sidebar.

On mobile, the sidebar collapses into a drawer. Tap the menu button to
open it.

## Timeline

The timeline shows entries from the selected source. Each entry card
shows the feed title, entry title, publication date, and a preview of
the content.

- **Unread entries** have a dot indicator on the left.
- **Read entries** appear slightly faded.
- **Starred entries** have a star icon.

Click an entry to open it in the reader view.

### Star an entry

Click the star icon on any entry card to star or unstar it. Starring is
instant — the UI updates immediately without waiting for the server.

### Mark as read

Entries are marked as read when you open them. You can also mark all
entries in a feed as read from the feed's context menu in the sidebar.

## Reader view

The reader shows the full entry content in a clean, readable layout.
Article headings use a serif font for comfortable reading.

- Press `Esc` or click the back button to return to the timeline.
- Star and unstar from the reader toolbar.
- Links open in a new tab.

## Search

Search runs a full-text query across all entry titles and content. Type
a query and press Enter. Results appear in the timeline, same as any
other feed view.

## Feeds

### Subscribe to a feed

1. Click **Add Feed** in the sidebar or navigate to the feed subscription
   page.
2. Paste the feed URL.
3. Optionally assign a folder.
4. Click **Subscribe**.

The feed title and site URL are updated after the first refresh cycle.

### Organize with folders

Create folders to group feeds by topic. Assign feeds to folders
when subscribing, or drag them in the sidebar.

### Delete a feed

Unsubscribe from a feed to remove it and all its entries. This cannot be
undone.

## Feed lists

Feed lists let you curate collections of feeds and share them.

### Create a list

1. Navigate to **Lists** in the sidebar.
2. Click **New List**.
3. Give it a title and description.
4. Choose whether to make it public.
5. Add feeds by URL.

### Share a list

Make a list public to let others discover it. Share the list URL with
anyone — they can follow it or import all its feeds.

### Follow a list

1. Navigate to **Lists** then **Discover**.
2. Browse public lists created by other users.
3. Click **Follow** on any list.

Following a list bookmarks it. To subscribe to all its feeds, click
**Import** on the list detail page.

### Import a list's feeds

Importing subscribes you to every feed in a list. Feeds you already
subscribe to are skipped. You can import safely — it is idempotent.

## API tokens

Manage your API tokens from the settings page. Create a token for
programmatic access (CLI, scripts), and delete tokens you no longer
need. The token value is shown only once at creation — save it
immediately.

See [Authentication](/docs/authentication) for more.
