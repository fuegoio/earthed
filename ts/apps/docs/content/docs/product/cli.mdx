`planetary` manages feeds, entries, folders, and API tokens from the terminal. `planetary-tui` is an interactive, full-screen feed browser.

## Install

Build both binaries from source:

```bash
cd go/cli
make build
```

Download pre-built binaries from the [GitHub releases page](https://github.com/fuegoio/planetary/releases) and add them to your `PATH`.

## Configuration

Point the CLI at your API server (defaults to `http://localhost:8080`):

```bash
./planetary config set base_url http://localhost:8080
```

Configuration is stored at `~/.config/planetary/config.json` (or the
equivalent on your OS).

## Login

Log in with the device flow — it opens a browser to a confirmation page
where you approve the CLI's access:

```bash
./planetary login
```

The CLI displays a confirmation code and a URL. If a browser can't be
opened automatically, copy the URL into a browser on any device where
you're signed in. Once you approve, the CLI stores the token and you're
ready to go.

Use `--no-browser` to skip auto-opening a browser, or `--url` to
override the API base URL for this login only:

```bash
./planetary login --no-browser --url https://api.example.com
```

Tokens issued via the device flow expire after 14 days. Run `planetary
login` again to refresh.

<details>
<summary>Manual token setup (alternative)</summary>

If you can't use the device flow, create a token via the web UI or the
API and set it manually:

```bash
./planetary config set token pla_your-token-here
```

</details>

## Commands

### login

```bash
planetary login                # log in via the browser (device flow)
planetary login --no-browser    # print the URL instead of opening a browser
```

### feeds

```bash
planetary feeds list              # list all subscriptions
planetary feeds add <url>         # subscribe to a feed
planetary feeds delete <id>       # unsubscribe from a feed
```

### entries

```bash
planetary entries list             # list recent entries
planetary entries list --unread    # list unread only
planetary entries list --starred   # list starred only
planetary entries list --feed 1    # filter by feed ID
planetary entries read <id>        # read a single entry
```

Run `planetary entries list --help` to see all available filters.

### folders

```bash
planetary folders list          # list folders
planetary folders create <title>  # create a folder
planetary folders delete <id>   # delete a folder
```

### tokens

```bash
planetary tokens list              # list API tokens
planetary tokens create <label>   # create a token (shown once)
planetary tokens delete <id>       # delete a token
```

### me

```bash
planetary me                       # show current user profile
```

### health

```bash
planetary health                   # check API health
```

## TUI

The TUI is an interactive feed browser. If you're not logged in, it
runs the device-flow login automatically before starting:

```bash
./planetary-tui
```

Pass `--login` to force a re-login even if a token is already saved:

```bash
./planetary-tui --login
```

### Navigation

| Key           | Action             |
| ------------- | ------------------ |
| `j` / `↓`     | move cursor down   |
| `k` / `↑`     | move cursor up     |
| `enter` / `l` | open selected item |
| `h` / `esc`   | go back            |
| `r`           | refresh feed list  |
| `q`           | quit               |

The TUI has three views:

1. **Feeds** — lists all subscriptions. Press enter to browse entries.
2. **Entries** — lists entries in the selected feed. Press enter to
   read.
3. **Entry** — shows the full entry content. Press esc to go back.
