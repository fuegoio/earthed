`earthed` manages feeds, entries, folders, and API tokens from the terminal. `earthed-tui` is an interactive, full-screen feed browser.

## Install

Build both binaries from source:

```bash
cd go/cli
make build
```

Download pre-built binaries from the [GitHub releases page](https://github.com/fuegoio/earthed/releases) and add them to your `PATH`.

## Configuration

Point the CLI at your API server (defaults to `http://localhost:8080`):

```bash
./earthed config set base_url http://localhost:8080
```

Configuration is stored at `~/.config/earthed/config.json` (or the
equivalent on your OS).

## Login

Log in with the device flow — it opens a browser to a confirmation page
where you approve the CLI's access:

```bash
./earthed login
```

The CLI displays a confirmation code and a URL. If a browser can't be
opened automatically, copy the URL into a browser on any device where
you're signed in. Once you approve, the CLI stores the token and you're
ready to go.

Use `--no-browser` to skip auto-opening a browser, or `--url` to
override the API base URL for this login only:

```bash
./earthed login --no-browser --url https://api.example.com
```

Tokens issued via the device flow expire after 14 days. Run `earthed
login` again to refresh.

<details>
<summary>Manual token setup (alternative)</summary>

If you can't use the device flow, create a token via the web UI or the
API and set it manually:

```bash
./earthed config set token pla_your-token-here
```

</details>

## Commands

### login

```bash
earthed login                # log in via the browser (device flow)
earthed login --no-browser    # print the URL instead of opening a browser
```

### feeds

```bash
earthed feeds list              # list all subscriptions
earthed feeds add <url>         # subscribe to a feed
earthed feeds delete <id>       # unsubscribe from a feed
```

### entries

```bash
earthed entries list             # list recent entries
earthed entries list --unread    # list unread only
earthed entries list --starred   # list starred only
earthed entries list --feed 1    # filter by feed ID
earthed entries read <id>        # read a single entry
```

Run `earthed entries list --help` to see all available filters.

### folders

```bash
earthed folders list          # list folders
earthed folders create <title>  # create a folder
earthed folders delete <id>   # delete a folder
```

### tokens

```bash
earthed tokens list              # list API tokens
earthed tokens create <label>   # create a token (shown once)
earthed tokens delete <id>       # delete a token
```

### me

```bash
earthed me                       # show current user profile
```

### health

```bash
earthed health                   # check API health
```

## TUI

The TUI is an interactive feed browser. If you're not logged in, it
runs the device-flow login automatically before starting:

```bash
./earthed-tui
```

Pass `--login` to force a re-login even if a token is already saved:

```bash
./earthed-tui --login
```

### Navigation

| Key           | Action             |
| ------------- | ------------------ |
| `j` / `↓`     | move cursor down   |
| `k` / `↑`     | move cursor up     |
| `enter` / `l` | open selected item |
| `h` / `esc`   | go back            |
| `r`           | refresh feed list  |
| `q`           | quit               |

The TUI has three views:

1. **Feeds** — lists all subscriptions. Press enter to browse entries.
2. **Entries** — lists entries in the selected feed. Press enter to
   read.
3. **Entry** — shows the full entry content. Press esc to go back.
