---
title: Reading Entries
description: Browse, filter, search, and manage entry status with the Planetary API.
---

Entries are individual articles fetched from your feed subscriptions. Each entry has a status (`unread`, `read`, or `removed`), a starred flag, and sanitized HTML content.

## List entries

Results are ordered by `published_at` descending (newest first).

```bash
curl "http://localhost:8080/api/v1/entries?limit=10" \
  -H "Authorization: Bearer pla_your-token"
```

### Filters

| Parameter   | Type   | Default | Description                           |
| ----------- | ------ | ------- | ------------------------------------- |
| `feed_id`   | int    | —       | Filter by feed                        |
| `folder_id` | int    | —       | Filter by folder (joins through feed) |
| `status`    | string | —       | `unread`, `read`, or `removed`        |
| `starred`   | bool   | —       | Filter starred entries                |
| `search`    | string | —       | Full-text search (English dictionary) |
| `limit`     | int    | 50      | Max 200                               |
| `offset`    | int    | 0       | Pagination offset                     |

Filters can be combined freely. When both `feed_id` and `folder_id` are provided, `folder_id` takes precedence.

```bash
# Unread entries in a specific feed
curl "http://localhost:8080/api/v1/entries?feed_id=1&status=unread" \
  -H "Authorization: Bearer pla_your-token"

# Starred entries across all feeds
curl "http://localhost:8080/api/v1/entries?starred=true" \
  -H "Authorization: Bearer pla_your-token"

# Full-text search combined with a status filter
curl "http://localhost:8080/api/v1/entries?search=docker&status=unread" \
  -H "Authorization: Bearer pla_your-token"

# Second page of results
curl "http://localhost:8080/api/v1/entries?limit=50&offset=50" \
  -H "Authorization: Bearer pla_your-token"
```

## Get a single entry

```bash
curl http://localhost:8080/api/v1/entries/42 \
  -H "Authorization: Bearer pla_your-token"
```

The `content` field contains the full sanitized HTML. The `description` field is a short summary, when available from the feed. Entries may also include `tags` (feed category tags) and `enclosures` (podcast audio, images, and other media attachments).

## Entry statuses

| Status    | Meaning                              |
| --------- | ------------------------------------ |
| `unread`  | New entry, not yet read              |
| `read`    | Entry has been opened                |
| `removed` | Hidden from the normal view          |

New entries start as `unread`. `changed_at` tracks when the status last changed.

## Bulk update status

Update the status of multiple entries in one request. Any valid status works: `read`, `unread`, or `removed`.

```bash
curl -X PUT http://localhost:8080/api/v1/entries \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"entry_ids":[42,43,44],"status":"read"}'
```

To mark all entries in a feed as read at once:

```bash
curl -X POST http://localhost:8080/api/v1/feeds/1/mark-all-read \
  -H "Authorization: Bearer pla_your-token"
```

## Star entries

Star an entry to bookmark it. The `starred` flag is independent of status — a `removed` entry that is starred still appears when filtering with `starred=true`.

```bash
curl -X PUT http://localhost:8080/api/v1/entries/42/starred \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"starred":true}'
```

Pass `false` to unstar.
