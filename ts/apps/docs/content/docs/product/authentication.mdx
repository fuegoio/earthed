Sunred identity is your [AT Protocol](https://atproto.com) identity. You sign in with your AT Proto handle — the same account you use on Bluesky or any other AT Proto app. There are no Sunred-specific passwords. See [Identity & sync](/at-proto) for the full picture.

## Signing in (web)

On the login page, enter your handle (for example `alice.bsky.social`) or click the default-PDS button if your instance shows one. Sunred redirects you to your PDS to approve the login, then brings you back with an active session.

The session is a cookie your browser sends automatically on every request. All your data — feeds, entries, tokens — is scoped to the signed-in user, so you only ever see your own.

## API tokens

API tokens let the CLI, scripts, and custom integrations call the [API](/api-reference) on your behalf. They're an alternative to the session cookie, sent in the `Authorization` header as a bearer token.

### Create a token

Go to **Settings → Tokens** and create one. Give it a label so you remember what it's for — say "laptop CLI" or "nightly script".

The token value is shown **only once**, right after you create it. Copy it and save it somewhere safe — you won't see it again. Tokens start with `pla_`.

### Use a token

Pass the token in the `Authorization` header:

```bash
curl https://api.your-instance.com/v1/feeds \
  -H "Authorization: Bearer pla_your-token"
```

The CLI stores it for you with `sunred config set token pla_...` (or via `sunred login`, below).

### Revoke a token

Delete a token from **Settings → Tokens** to revoke it immediately — any request using it fails with `401` from that point on. Use this if a token leaks or you no longer need it.

## CLI login (device flow)

The CLI logs in without you pasting a token. Run:

```bash
sunred login
```

It opens a browser to a confirmation page where you approve the request, using your existing web session. If a browser can't open automatically, the CLI prints a URL to open on any device where you're signed in. Once approved, the CLI stores the token and you're ready to go.

Use `--no-browser` to skip auto-opening a browser, or `--url` to point at a different API for this login only:

```bash
sunred login --no-browser --url https://api.your-instance.com
```

Tokens issued through the device flow expire after 14 days and show up in your token list labeled `CLI (device flow)` so you can spot and revoke them. Run `sunred login` again to refresh.

## Token lifetime

- Tokens you create in the web UI or with `sunred tokens create` **do not expire**.
- Tokens issued via `sunred login` (device flow) **expire after 14 days**.

## Programmatic access

Create, list, and revoke tokens through the [Tokens API](/api-reference?tag=Tokens).
