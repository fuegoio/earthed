## What is Planetary

Planetary is a modern, self-hostable RSS reader. It fetches RSS 2.0,
Atom 1.0, and JSON Feed subscriptions into a single timeline you can
browse from the web, the terminal, or the command line.

No ads. No tracking. No algorithm. Just the sources you chose, in a calm
space built for reading.

## Three interfaces, one API

- **Web app** — a sidebar, a timeline, and a reader view. Keyboard
  shortcuts, starring, search. Works on desktop and mobile.
- **Terminal UI** — a full-screen, keyboard-driven reader that runs in
  your terminal. Vim-style navigation.
- **CLI** — manage feeds, list entries, mark as read. Scriptable and
  pipe-friendly.

All three are backed by the same REST API. Use one, use all three, or
build your own client.

## Feed lists

Curate collections of feeds around a topic and share them with a link.
Follow lists made by others to subscribe to all their feeds in one click.
See [Feed Lists](/docs/feed-lists) for the full guide.
