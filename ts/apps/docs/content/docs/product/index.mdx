title: Earthed
description: A self-hostable RSS reader with a REST API, web app, terminal UI, and CLI.
---

Earthed is a self-hosted RSS reader. It fetches RSS 2.0, Atom 1.0, and JSON Feed subscriptions, stores them in PostgreSQL, and surfaces them through three interfaces backed by a single REST API.

**Web app** — sidebar, timeline, and reader. Keyboard shortcuts, starring, search, mobile-ready.

**Terminal UI** — a full-screen, keyboard-driven reader. Vim-style navigation.

**CLI** — manage feeds and entries from the shell. Scriptable and pipe-friendly.

## Feed lists

Curate collections of feeds around a topic and share them publicly. Others can follow your list or import all its feeds in one click. See [Feed Lists](/docs/feed-lists).

## Where to start

New to Earthed? Start with [Getting Started](/docs/getting-started) to run it locally and read your first entries.

Deploying to a server? Go to [Self-Hosting](/self-hosting).
