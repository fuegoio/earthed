---
title: Getting Started
description: Run Earthed locally, create an account, subscribe to a feed, and read entries.
---

## Prerequisites

- [Go](https://go.dev/dl/) 1.25 or later
- [Node.js](https://nodejs.org/) 20+ with [pnpm](https://pnpm.io/) 10+
- [Docker](https://docs.docker.com/get-docker/) (for PostgreSQL)

## 1. Start PostgreSQL

```bash
cd go/api
make db-up
```

This starts a PostgreSQL 16 container on port 5432 with database `earthed`, user `earthed`, password `earthed`.

## 2. Configure environment

Create a `.env` file in `go/api/`:

```bash
LIMEN_SECRET=<32-byte-secret>
EARTHED_DATABASE_URL=postgres://earthed:earthed@localhost:5432/earthed?sslmode=disable
EARTHED_BASE_URL=http://localhost:8080
EARTHED_WEB_URL=http://localhost:3000
EARTHED_PDS_URL=http://localhost:2583
```

`LIMEN_SECRET` is a 32-byte hex string used for session signing. Generate one with:

```bash
openssl rand -hex 16
```

`EARTHED_PDS_URL` points Earthed at a PDS for login and signup. For local
development, run the [official PDS image](https://github.com/bluesky-social/pds)
(see [AT Proto & identity](/self-hosting/at-proto)). Users can also log in with
any existing AT Proto handle, such as a Bluesky account.

## 3. Run migrations

```bash
cd go/api
make migrate
```

## 4. Start the API server

```bash
cd go/api
make run
```

Verify it is running:

```bash
curl http://localhost:8080/v1/health
# {"status":"ok"}
```

## 5. Create an account

Earthed uses AT Proto identity — there is no email/password signup. Start the
web frontend (step 9) and sign in by entering an AT Proto handle. You can use
a Bluesky handle (`alice.bsky.social`) or an account on your local PDS.

See [Identity & sync](/at-proto) for how login and data sync work.

## 6. Create an API token

API tokens are used for the CLI, curl, and scripts. Create one with the session cookie from the previous step:

```bash
curl -X POST http://localhost:8080/v1/tokens \
  -H "Content-Type: application/json" \
  -b cookies.txt \
  -d '{"label":"my-token"}'
```

Save the `token` value from the response — it starts with `pla_` and is shown only once.

## 7. Subscribe to a feed

```bash
curl -X POST http://localhost:8080/v1/feeds \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token-here" \
  -d '{"feed_url":"https://blog.golang.org/feeds/posts/default"}'
```

You can also pass a website URL — Earthed discovers the feed automatically from `<link rel="alternate">` tags.

## 8. Read entries

```bash
curl "http://localhost:8080/v1/entries?limit=10" \
  -H "Authorization: Bearer pla_your-token-here"
```

## 9. Start the web frontend

```bash
cd ts
pnpm install
pnpm dev
```

The web app is at `http://localhost:3000`. Sign in with the account you created above.

## 10. Try the CLI

```bash
cd go/cli
make build
./earthed config set base_url http://localhost:8080
./earthed config set token pla_your-token-here

./earthed feeds list
./earthed entries list
./earthed-tui   # interactive TUI
```

See [CLI](/cli) for the full command reference.
