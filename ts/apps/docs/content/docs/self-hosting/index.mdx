title: Docker Compose
description: Deploy Earthed with Docker Compose.

Earthed publishes images to GitHub Container Registry on every push to `main` and every release:

| Image | Registry                        |
| ----- | ------------------------------- |
| API   | `ghcr.io/fuegoio/earthed-api` |
| Web   | `ghcr.io/fuegoio/earthed-web` |

Tags: `latest` (main branch), `1.2.3` / `v1.2.3` (release), `1.2` (minor), `1` (major), `sha-<short>` (commit).

Both containers run as a non-root user (`uid 10001`). The API listens on port 8080, the web app on port 3000.

## Docker Compose

```yaml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: earthed
      POSTGRES_PASSWORD: <db-password>
      POSTGRES_DB: earthed
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U earthed"]
      interval: 5s
      timeout: 3s
      retries: 10

  api:
    image: ghcr.io/fuegoio/earthed-api:latest
    ports:
      - "8080:8080"
    environment:
      LIMEN_SECRET: <32-byte-secret>
      EARTHED_DATABASE_URL: postgres://earthed:<db-password>@postgres:5432/earthed?sslmode=disable
      EARTHED_BASE_URL: https://api.your-domain.com
      EARTHED_WEB_URL: https://your-domain.com
      EARTHED_PDS_URL: http://pds:2583
      EARTHED_RELAY_URL: http://relay:9090
      EARTHED_OAUTH_REDIRECT_URL: https://api.your-domain.com/auth/oauth/callback
    depends_on:
      postgres:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "wget", "-q", "--spider", "http://localhost:8080/v1/health"]
      interval: 30s
      timeout: 5s
      retries: 3

  web:
    image: ghcr.io/fuegoio/earthed-web:latest
    ports:
      - "3000:3000"
    environment:
      EARTHED_API_URL: http://api:8080
      NEXT_PUBLIC_EARTHED_API_URL: https://api.your-domain.com
    depends_on:
      api:
        condition: service_healthy

  pds:
    image: ghcr.io/bluesky-social/pds:latest
    ports:
      - "2583:2583"
    environment:
      PDS_HOSTNAME: pds.your-domain.com
      PDS_JWT_SECRET: <jwt-secret>
      PDS_ADMIN_PASSWORD: <admin-password>
      PDS_DATA_DIR: /pds
    volumes:
      - pdsdata:/pds

  relay:
    image: ghcr.io/fuegoio/earthed-relay:latest
    ports:
      - "9090:9090"
    environment:
      RELAY_DATABASE_URL: postgres://earthed:<db-password>@postgres:5432/earthed_relay?sslmode=disable
      RELAY_HTTP_ADDR: ":9090"
    depends_on:
      postgres:
        condition: service_healthy

volumes:
  pgdata:
  pdsdata:
```

Start:

```bash
docker compose up -d
```

Run database migrations on first start. The API and relay each need their own
database:

```bash
docker compose exec api /app/earthed --migrate
docker compose exec relay /app/earthed-relay --migrate
```

`EARTHED_API_URL` is the server-side URL the web container uses to reach the API over the Docker network. `NEXT_PUBLIC_EARTHED_API_URL` is baked into the browser bundle and must be publicly reachable.

The `pds` and `relay` services are optional but recommended — `pds` lets users
sign up on your domain, and `relay` enables cross-instance social features.
See [AT Proto & identity](/self-hosting/at-proto) for what each does and how to
configure them. Users can still log in with any existing AT Proto handle
(e.g. a Bluesky account) without running your own PDS.
