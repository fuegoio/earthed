title: Configuration
description: Environment variables for the API and web containers.
---

## API

| Variable                         | Default                                                                   | Description                                                |
| -------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `EARTHED_DATABASE_URL`         | `postgres://earthed:earthed@localhost:5432/earthed?sslmode=disable` | PostgreSQL connection string                               |
| `EARTHED_HTTP_ADDR`            | `:8080`                                                                   | HTTP listen address                                        |
| `EARTHED_BASE_URL`             | `http://localhost:8080`                                                   | Public URL of the API (used for auth redirects)            |
| `EARTHED_WEB_URL`              | `http://localhost:3000`                                                   | Public URL of the web frontend                             |
| `EARTHED_LOG_FORMAT`           | `pretty`                                                                  | Log format: `pretty` or `json`                             |
| `EARTHED_POLLING_FREQUENCY`    | `60s`                                                                     | How often the scheduler checks for due feeds               |
| `EARTHED_BATCH_SIZE`           | `100`                                                                     | Feeds processed per scheduler tick                         |
| `EARTHED_WORKER_POOL_SIZE`     | `5`                                                                       | Concurrent feed-processing workers                         |
| `EARTHED_HTTP_CLIENT_TIMEOUT`  | `20s`                                                                     | Timeout for fetching a single feed                         |
| `EARTHED_HTTP_CLIENT_MAX_BODY` | `15728640`                                                                | Max feed body size in bytes (15 MB)                        |
| `EARTHED_CLEANUP_FREQUENCY`    | `24h`                                                                     | How often to run entry cleanup                             |
| `EARTHED_ENTRY_MAX_AGE_DAYS`   | `60`                                                                      | Entries older than this are eligible for cleanup           |
| `EARTHED_DISABLE_SCHEDULER`    | (unset)                                                                   | Set to any non-empty value to disable the scheduler        |
| `EARTHED_COOKIE_SECURE`        | `false`                                                                   | Mark session cookies as `Secure` (required for cookies over HTTPS) |
| `EARTHED_COOKIE_SAMESITE`      | `lax`                                                                     | Cookie SameSite mode: `lax`, `none`, or `strict`. `none` requires `EARTHED_COOKIE_SECURE=true` |
| `EARTHED_COOKIE_DOMAIN`        | (unset)                                                                   | Bare host to set as the cookie `Domain` (e.g. `earthed.app`), so the session is shared across subdomains. Set to the registrable domain shared by the API and web app |
| `EARTHED_TRUSTED_ORIGINS`      | (unset)                                                                   | Comma-separated list of allowed browser origins (e.g. `https://app.earthed.app`). When unset, any origin is allowed (dev only). When set, `EARTHED_WEB_URL` is always included automatically |
| `EARTHED_RELAY_URL`            | (unset)                                                                   | URL of the Earthed relay. Optional; enables cross-instance social features (global counts, federated shares). See [AT Proto & identity](/self-hosting/at-proto) |
| `EARTHED_OAUTH_REDIRECT_URL`   | (unset)                                                                   | Public OAuth callback URL, e.g. `https://api.your-domain.com/auth/oauth/callback` |

## Web

| Variable                        | Default                 | Description                                          |
| ------------------------------- | ----------------------- | ---------------------------------------------------- |
| `EARTHED_API_URL`             | `http://localhost:8080` | Server-side API URL (reachable from the container)   |
| `NEXT_PUBLIC_EARTHED_API_URL` | `http://localhost:8080` | Client-side API URL (reachable from the browser)     |
