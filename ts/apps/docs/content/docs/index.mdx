## What is Planetary

Planetary is a self-hosted RSS reader. It aggregates feeds into a
single timeline you can browse from the web UI, and exposes a REST API
for subscribing to feeds and reading entries programmatically.

## Where to start

- [Getting Started](/docs/getting-started) — run Planetary locally
  with Docker, subscribe to your first feed, and read entries.
