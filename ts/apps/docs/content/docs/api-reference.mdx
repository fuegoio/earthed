All API endpoints are prefixed with `/api/v1/`. Authentication is required
for all endpoints except `/api/v1/health`.

Interactive docs are also available at `/docs` on a running server, and the
OpenAPI spec at `/openapi.json`.

## Authentication

Planetary supports two authentication methods:

1. **Session cookie** — obtained by signing in via `/api/auth/signin`.
   The browser sends the cookie automatically. Use this for the web
   frontend.

2. **Bearer token** — create an API token via `POST /api/v1/tokens` and
   send it in the `Authorization` header:

   ```
   Authorization: Bearer pla_your-token-here
   ```

   Use this for the CLI, scripts, and programmatic access.

Bearer tokens take precedence over session cookies. If both are present,
the token is used.

See [Authentication](/docs/authentication) for the full flow.

## Health

### GET /api/v1/health

Check API health. No authentication required.

```bash
curl http://localhost:8080/api/v1/health
```

```json
{"status":"ok"}
```

## User

### GET /api/v1/me

Get the authenticated user's profile.

```bash
curl http://localhost:8080/api/v1/me \
  -H "Authorization: Bearer pla_your-token"
```

```json
{
  "id": 1,
  "email": "user@example.com",
  "is_admin": false,
  "created_at": "2025-01-01T00:00:00Z"
}
```

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | int | User ID |
| `email` | string | Email address |
| `first_name` | string | First name (omitted if empty) |
| `is_admin` | bool | Admin flag (always false in current version) |
| `created_at` | string | Account creation timestamp (RFC 3339) |

## Feeds

### GET /api/v1/feeds

List all feed subscriptions.

```bash
curl http://localhost:8080/api/v1/feeds \
  -H "Authorization: Bearer pla_your-token"
```

```json
[
  {
    "id": 1,
    "user_id": 1,
    "category_id": 2,
    "feed_url": "https://blog.golang.org/feeds/posts/default",
    "site_url": "https://blog.golang.org",
    "title": "The Go Blog",
    "parsing_error_count": 0,
    "disabled": false,
    "crawler": false,
    "next_check_at": "2025-08-14T12:30:00Z",
    "last_fetch_at": "2025-08-14T11:30:00Z",
    "created_at": "2025-08-01T00:00:00Z",
    "updated_at": "2025-08-14T11:30:00Z"
  }
]
```

Returns an empty array `[]` when no feeds are subscribed.

### POST /api/v1/feeds

Subscribe to a feed.

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `feed_url` | string | Yes | URL of the RSS/Atom/JSON feed (1-2048 chars) |
| `category_id` | int | No | Category to assign the feed to |

```bash
curl -X POST http://localhost:8080/api/v1/feeds \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"feed_url":"https://blog.golang.org/feeds/posts/default","category_id":2}'
```

```json
{
  "id": 1,
  "user_id": 1,
  "category_id": 2,
  "feed_url": "https://blog.golang.org/feeds/posts/default",
  "site_url": "https://blog.golang.org/feeds/posts/default",
  "title": "https://blog.golang.org/feeds/posts/default",
  "parsing_error_count": 0,
  "disabled": false,
  "crawler": false,
  "created_at": "2025-08-14T12:00:00Z",
  "updated_at": "2025-08-14T12:00:00Z"
}
```

The `site_url` and `title` are initially set to the `feed_url`. They are
populated with the real values after the first refresh cycle picks up
the feed.

Duplicate subscriptions (same `feed_url` for the same user) return a 400
error.

### GET `/api/v1/feeds/{feedId}`

Get a single feed by ID.

```bash
curl http://localhost:8080/api/v1/feeds/1 \
  -H "Authorization: Bearer pla_your-token"
```

Returns 404 if the feed does not exist or belongs to another user.

### DELETE `/api/v1/feeds/{feedId}`

Unsubscribe from a feed. All entries belonging to the feed are deleted.

```bash
curl -X DELETE http://localhost:8080/api/v1/feeds/1 \
  -H "Authorization: Bearer pla_your-token"
```

Returns 204 No Content on success.

### POST `/api/v1/feeds/{feedId}/mark-all-read`

Mark all unread entries in a feed as read.

```bash
curl -X POST http://localhost:8080/api/v1/feeds/1/mark-all-read \
  -H "Authorization: Bearer pla_your-token"
```

Returns 204 No Content on success.

## Entries

### GET /api/v1/entries

List entries with optional filters. Results are ordered by
`published_at` descending (newest first).

| Parameter | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| `feed_id` | int | — | Filter by feed |
| `category_id` | int | — | Filter by category (joins through feed) |
| `status` | string | — | `unread`, `read`, or `removed` |
| `starred` | bool | — | Filter starred entries |
| `search` | string | — | Full-text search (English dictionary) |
| `limit` | int | 50 | Max 200 |
| `offset` | int | 0 | Pagination offset |

```bash
curl "http://localhost:8080/api/v1/entries?status=unread&limit=10" \
  -H "Authorization: Bearer pla_your-token"
```

```json
[
  {
    "id": 42,
    "user_id": 1,
    "feed_id": 1,
    "hash": "a1b2c3...",
    "title": "Go 1.25 is released",
    "url": "https://blog.golang.org/go1-25",
    "author": "The Go Team",
    "content": "<p>Today we release Go 1.25...</p>",
    "description": "Go 1.25 brings improvements to...",
    "status": "unread",
    "starred": false,
    "published_at": "2025-08-13T15:00:00Z",
    "changed_at": "2025-08-13T15:00:00Z",
    "tags": ["go", "release"]
  }
]
```

Returns an empty array `[]` when no entries match.

When both `feed_id` and `category_id` are provided, `category_id` takes
precedence.

### GET `/api/v1/entries/{entryId}`

Get a single entry by ID.

```bash
curl http://localhost:8080/api/v1/entries/42 \
  -H "Authorization: Bearer pla_your-token"
```

Returns 404 if the entry does not exist or belongs to another user.

### PUT /api/v1/entries

Bulk update entry status.

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `entry_ids` | int[] | Yes | Entry IDs to update |
| `status` | string | Yes | `unread`, `read`, or `removed` |

```bash
curl -X PUT http://localhost:8080/api/v1/entries \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"entry_ids":[42,43,44],"status":"read"}'
```

Returns 204 No Content on success. The `changed_at` field is updated to
the current time for all affected entries.

### PUT `/api/v1/entries/{entryId}/starred`

Set the starred flag on an entry.

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `starred` | bool | Yes | `true` to star, `false` to unstar |

```bash
curl -X PUT http://localhost:8080/api/v1/entries/42/starred \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"starred":true}'
```

Returns 204 No Content on success.

## Categories

### GET /api/v1/categories

List all categories, ordered by title.

```bash
curl http://localhost:8080/api/v1/categories \
  -H "Authorization: Bearer pla_your-token"
```

```json
[
  {
    "id": 1,
    "user_id": 1,
    "title": "News",
    "created_at": "2025-08-01T00:00:00Z"
  },
  {
    "id": 2,
    "user_id": 1,
    "title": "Technology",
    "created_at": "2025-08-01T00:00:00Z"
  }
]
```

Returns an empty array `[]` when no categories exist.

### POST /api/v1/categories

Create a category.

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `title` | string | Yes | Category name (1-255 chars) |

```bash
curl -X POST http://localhost:8080/api/v1/categories \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"title":"Technology"}'
```

```json
{
  "id": 2,
  "user_id": 1,
  "title": "Technology",
  "created_at": "2025-08-14T12:00:00Z"
}
```

### DELETE `/api/v1/categories/{categoryId}`

Delete a category. Feeds in the category are not deleted; they become
uncategorized (their `category_id` is set to null).

```bash
curl -X DELETE http://localhost:8080/api/v1/categories/2 \
  -H "Authorization: Bearer pla_your-token"
```

Returns 204 No Content on success.

## API Tokens

### GET /api/v1/tokens

List all API tokens. Token values are never shown — only labels and
metadata.

```bash
curl http://localhost:8080/api/v1/tokens \
  -H "Authorization: Bearer pla_your-token"
```

```json
[
  {
    "id": 1,
    "user_id": 1,
    "label": "my-script",
    "created_at": "2025-08-14T12:00:00Z",
    "last_used_at": "2025-08-14T13:00:00Z"
  }
]
```

Returns an empty array `[]` when no tokens exist.

### POST /api/v1/tokens

Create a new API token. The response includes the full token string
(prefixed with `pla_`). Save it immediately; it cannot be retrieved
later.

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `label` | string | Yes | Label for the token (1-255 chars) |

```bash
curl -X POST http://localhost:8080/api/v1/tokens \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer pla_your-token" \
  -d '{"label":"my-script"}'
```

```json
{
  "id": 1,
  "label": "my-script",
  "token": "pla_a1b2c3d4e5f6...",
  "created_at": "2025-08-14T12:00:00Z"
}
```

### DELETE `/api/v1/tokens/{tokenId}`

Delete an API token. Any requests using the deleted token will fail
immediately.

```bash
curl -X DELETE http://localhost:8080/api/v1/tokens/1 \
  -H "Authorization: Bearer pla_your-token"
```

Returns 204 No Content on success.

## Data Models

### Feed

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | int | Feed ID |
| `user_id` | int | Owning user ID |
| `category_id` | int (nullable) | Category ID, or null if uncategorized |
| `feed_url` | string | Feed URL |
| `site_url` | string | Website URL |
| `title` | string | Feed title |
| `parsing_error` | string | Last parsing error message (omitted if empty) |
| `parsing_error_count` | int | Number of consecutive fetch/parse errors |
| `disabled` | bool | Whether the feed is excluded from refresh |
| `scraper_rules` | string | Scraper rules (omitted if empty) |
| `rewrite_rules` | string | Rewrite rules (omitted if empty) |
| `crawler` | bool | Whether crawler mode is enabled |
| `next_check_at` | string (nullable) | Next scheduled refresh time (omitted if unset) |
| `last_fetch_at` | string (nullable) | Last successful fetch time (omitted if never fetched) |
| `created_at` | string | Subscription timestamp |
| `updated_at` | string | Last update timestamp |

### Entry

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | int | Entry ID |
| `user_id` | int | Owning user ID |
| `feed_id` | int | Parent feed ID |
| `hash` | string | SHA-256 deduplication hash |
| `title` | string | Entry title |
| `url` | string | Entry URL |
| `comments_url` | string | Comments URL (omitted if empty) |
| `author` | string | Author name (omitted if empty) |
| `content` | string | Sanitized HTML content |
| `description` | string | Short description / summary (omitted if empty) |
| `status` | string | `unread`, `read`, or `removed` |
| `starred` | bool | Whether the entry is starred |
| `published_at` | string | Publication timestamp |
| `changed_at` | string | Last status change timestamp |
| `tags` | string[] | Feed-assigned tags (omitted if empty) |
| `enclosures` | Enclosure[] | Media attachments (omitted if empty) |

| Field | Type | Description |
| ----- | ---- | ----------- |

## Errors

All errors follow [RFC 9457](https://datatracker.ietf.org/doc/html/rfc9457)
(problem details for HTTP APIs). The response body is JSON:

```json
{
  "title": "Bad Request",
  "status": 400,
  "detail": "feed_url is required",
  "errors": [
    {
      "location": "body.feed_url",
      "message": "this field is required"
    }
  ]
}
```

| Status | Meaning |
| ------ | ------- |
| 400 | Bad request (validation) |
| 401 | Unauthorized (no or invalid token) |
| 404 | Resource not found |
| 500 | Internal server error |
